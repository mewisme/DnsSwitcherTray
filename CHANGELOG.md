# Changelog

Notable changes to DNS Switcher Tray are recorded here.

## [Unreleased]

- No published release yet.

## [0.0.1] - Initial version (pending release)

- Native Windows x64 system tray application written in Rust.
- Sixteen built-in DNS profiles and network adapter selection.
- DNS read-back verification, rollback, and automatic DNS restoration.
- Administrator-approved elevated autostart via Windows Task Scheduler.
- Startup notification and embedded application icon.
- Windows x64 release workflow with SHA-256 checksums.
